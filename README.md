# 📊 칼바람 나락 코어템 시너지 분석 대시보드

> 리그 오브 레전드 칼바람 나락 모드의 챔피언별 승률 및 1+2코어 아이템 시너지를 분석하는 Streamlit 대시보드 프로젝트입니다.

🔗 **[라이브 데모 보기](https://aram-analysis.streamlit.app/)**

---

## 📌 프로젝트 개요

솔로랭크 마스터 티어 이상 유저 데이터를 기반으로, 칼바람 나락에서 어떤 챔피언이 강하고 어떤 아이템 조합이 승률을 높이는지 데이터로 분석합니다.

| 항목 | 내용 |
|------|------|
| 수집 대상 | 솔로랭크 마스터 티어 이상 유저 5,000명 |
| 수집 데이터 | 유저별 최근 칼바람 나락 매치 최대 100회 (중복 제외) |
| 총 분석 매치 수 | 134,925 게임 |
| 수집 일자 | 2026년 2월 6일 14:00 |

---

## 🎯 분석 목적

1. **챔피언별 칼바람 나락 승률 분석** — 어떤 챔피언이 실질적으로 강한지 데이터로 확인
2. **챔피언 1+2코어 아이템 조합 분석** — 최다 승률 TOP3 / 최다 픽 판수 TOP3 조합 도출

---

## 🖥️ 주요 기능

- **KPI 카드** — 총 분석 챔피언 수, 최고 승률 챔피언, 최다 선택 챔피언, 최고 픽률 챔피언을 한눈에 확인
- **필터링** — 챔피언 이름 검색 및 최소 픽 횟수 필터로 원하는 데이터만 조회
- **전체 통계 테이블** — 승률·픽률·픽 횟수·코어 조합 등 원하는 컬럼을 선택해 확인
- **승률 Top 10 차트** — 칼바람 나락 승률 상위 10개 챔피언 시각화
- **픽률 Top 10 차트** — 가장 많이 선택된 챔피언 상위 10개 시각화
- **챔피언 상세 조합 조회** — 특정 챔피언 선택 시 승률 기반 추천 조합 / 인기 조합(판수 기준) 각 TOP3 표시

## ⚙️ 로컬 실행 방법

### 1. 저장소 클론

```bash
git clone https://github.com/chihyuns0ng/hobby.git
cd hobby
```

### 2. 의존성 설치

```bash
pip install -r requirements.txt
```


## 📊 데이터 설명

`aram_top3_260206.csv` 파일은 챔피언별로 다음 정보를 포함합니다.

| 컬럼 | 설명 |
|------|------|
| 챔피언 | 챔피언 이름 |
| 전체승률 | 해당 챔피언의 칼바람 승률 (%) |
| 픽 횟수 | 분석 기간 내 총 픽 횟수 |
| 승률1~3위_조합 | 승률 기준 상위 3개 1+2코어 조합 |
| 승률1~3위_WR | 각 조합의 승률 |
| 판수1~3위_조합 | 픽 판수 기준 상위 3개 1+2코어 조합 |
| 판수1~3위_판수 | 각 조합의 픽 판수 |
